# iot-devices

The AWS IoT Core device registry from `docs/features/iot-core.md`:

- thing types `wearable` and `bedroom`
- one thing per device, named by its ID (also its MQTT client ID)
- static thing groups `wearables`, `bedroom-sensors`, `canary-wearables`,
  `canary-bedroom-sensors`; every device is in its type group, canary devices also in
  their type's canary group
- one certificate per device, created from the committed CSR `<csr_dir>/<id>.csr`
  (AWS signs it; no private key is generated by AWS or stored in state), attached to
  the device's thing (exclusively) and to its type's policy
- IoT policies `silvercare-device-wearable` and `silvercare-device-bedroom`: connect
  only with client ID = own thing name and an attached certificate, publish only to
  `silvercare/v1/<own thing name>/<message>` for the type's own messages (wearable
  `vitals`, `fall`, `status`; bedroom `motion`, `bed`, `status`). No subscribe,
  receive, shadow, or wildcard actions.

The device list is validated: an ID that doesn't match `^(wearable|bedroom)-[0-9]{4}$`,
an ID prefix that doesn't match the type, or a duplicate ID fails the plan with an
error naming the entry. A device without a CSR file fails the plan with an error naming
the device and telling you to run `make device-keys`.

A new CSR for a device (a replaced key) replaces that device's certificate and its
attachments. Removing a device from the list deletes its thing and certificate.

Everything this module creates is free.

## Inputs

| Name | Type | Default | Description |
|---|---|---|---|
| `devices` | `list(object({ id = string, type = string, canary = bool }))` | required | The device list |
| `csr_dir` | `string` | required | Directory with `<id>.csr` for every device |
| `tags` | `map(string)` | `{}` | Extra tags (provider `default_tags` are added anyway) |

## Outputs

| Name | Description |
|---|---|
| `device_certificates` | Map of device ID to certificate PEM. Marked sensitive so applies don't print it in CI logs; `terraform output -json device_certificates` still shows it |
| `thing_group_arns` | Map of thing group name to ARN (job targets) |

## Example

```hcl
module "iot_devices" {
  source = "./modules/iot-devices"

  devices = jsondecode(file("${path.module}/devices/devices.json")).devices
  csr_dir = "${path.module}/devices/csr"
}
```
